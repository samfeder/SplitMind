SplitMind privacy policy

Applies to this SplitMind deployment. Last updated 2026-10-25.

What this is

SplitMind is a self-hosted connector. It runs on its operator's own Cloudflare account so that the operator's Claude can read and act in the operator's own Gmail, Notion and Slack accounts. It is not a public service. Only the operator can connect accounts or use it: connecting an account, and approving Claude's access, both require the operator's admin token.

What it accesses

For each account the operator connects, SplitMind can call that provider's API with the permissions granted on the provider's consent screen. It does so only when the operator's Claude asks for a specific action, such as searching mail or reading a page. It does not read accounts in the background. Actions that change mailbox settings (vacation responder, IMAP, POP, language) are blocked.

What it stores

  • Credentials: each connection's OAuth tokens and the OAuth app's client secret, encrypted with a key stored as a secret of the deployment.
  • Connection details: the nickname the operator chose and the account's profile from the provider, such as its email address or workspace name.
  • An action log: for each action, its name, time and outcome, plus a shortened copy of its input and output. Strings are cut to 256 characters and secrets are removed. Only the most recent 5,000 entries are kept.
  • Temporary files: a downloaded attachment is held for at most one hour, so Claude can fetch it, and is then deleted.

All of it is stored in the operator's own Cloudflare account. Nothing is stored anywhere else.

Who it is shared with

Data goes only to the operator's own Claude, and only as the result of an action the operator's Claude asked for. SplitMind does not sell data, show ads, or use data to train models. It does not give data to anyone else.

Google user data

SplitMind's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Gmail data is used only to carry out the operator's own requests. People do not read it, except when the operator reads their own mail through Claude.

Removing data

Disconnecting an account in this deployment's Web Console deletes its stored tokens. Access can also be revoked at any time from the provider's side, for example at Google Account permissions. Deleting the deployment deletes everything it stored.

Contact

Questions go to the operator of this deployment, at the developer contact address shown on Google's consent screen.
